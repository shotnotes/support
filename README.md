# Shot Notes support

Shot Notes keeps notes on the shots you take with manual lenses: the aperture,
focal length, lens, kit and place of each frame, which a lens without
electronic contacts can't tell the camera. Your notes stay on your own
devices. Later, they can be written into the metadata of the matching image
files.

Website: https://www.shotnotes.app

Privacy policy: https://www.shotnotes.app/privacy/

This repository is where you can report a problem, suggest a feature, ask a
question and, once there are releases, download Shot Notes. It holds no source
code.

## Status

Shot Notes is in development. Nothing has been released yet, and it isn't in
the app stores. [Announcements](https://github.com/shotnotes/support/discussions/categories/announcements)
will say when there is something to try.

## Getting Shot Notes

When there are releases, the website's
[Get started](https://www.shotnotes.app/#get-started) section will say how to
install each part, and the downloads will be under
[Releases](https://github.com/shotnotes/support/releases) here.

## Getting help

- **Something doesn't work:** [report a problem](https://github.com/shotnotes/support/issues/new?template=bug_report.yml).
  The app's "Report a problem" will fill in the version, the system and the
  device for you.
- **An idea or a change you would like:** [suggest a feature](https://github.com/shotnotes/support/issues/new?template=feature_request.yml),
  or talk it over first in [Ideas](https://github.com/shotnotes/support/discussions/categories/ideas).
- **A typo or unclear text**, on the website, in the app, in the install
  instructions or in a store listing: [report it](https://github.com/shotnotes/support/issues/new?template=text_problem.yml).
- **A question:** see the [FAQ](https://www.shotnotes.app/#faq) first, then ask
  in [Q&A](https://github.com/shotnotes/support/discussions/categories/q-a).
- **A security problem:** don't open an issue; see [SECURITY.md](SECURITY.md).

You need a GitHub account to open an issue or start a discussion.

**Everything here is public.** Shots can hold coordinates and the names of
places. Before you paste a log or attach an export file or a screenshot,
remove anything you would rather not make public.

## What happens to a report

Each report is read and labelled with the part it is about. When it needs
more detail, it gets **needs info** and a question. When it is taken on, it
gets **tracked**, and stays open until a release fixes it or brings the
feature. Reports that can't be acted on are closed with a reason.
