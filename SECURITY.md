# Security

## Reporting a problem

Please don't report security problems in public issues or discussions.
Report them privately instead, with
[Report a vulnerability](https://github.com/shotnotes/support/security/advisories/new)
(the **Security** tab, then **Report a vulnerability**). Only the developer can
see the report.

It helps to include:

- which part it is in: the iPhone or Android app, the desktop app, the
  Lightroom Classic plugin, the command-line tool or the website;
- the version, and the operating system and device;
- what someone could do with it, and the steps to show it.

Don't include real shots, places or coordinates; made-up ones are enough.

## What to expect

You will get a reply in the report. Once the problem is confirmed, it is fixed
in a release, and a security advisory is published here after the release,
crediting you if you want to be. Please keep the problem private until then.
There is no bug bounty.

## Scope

Shot Notes runs on your devices. There are no accounts and no Shot Notes
servers, so reports are about the apps, the desktop app, the Lightroom Classic
plugin, the command-line tool, their downloads and the website.

Nothing has been released yet. Once there are releases, only the latest one
gets security fixes.
